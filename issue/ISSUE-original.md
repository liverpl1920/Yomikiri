### Webアプリの概要

Yomikiriは、技術書やビジネス書の「積読（つんどく）」に特化した読書管理アプリです。本に「賞味期限（読了期限）」を設定し、期限から逆算した「今日のノルマ（必要ページ数）」を提示することで、「読みたいけど読めない」を「今日はこれだけでOK」に変換します。Googleカレンダー連携で読書時間を予定として確保し、賞味期限ビジュアライザーで期限が迫る本ほど書影が色褪せることで先延ばしを防ぎます。想定ユーザーはエンジニア・ビジネスパーソン・積読に悩む読書家です。

### 開発方針

- **コード実装**：GitHub Copilot（AIエージェント）が Issue の仕様に基づいて全コードを記述
- **人間の担当領域**：CI/CD パイプラインの設計・構築、インフラ設定、外部サービス連携の構成、PR レビュー・マージ判断
- **開発フロー**：Issue 起票 → Copilot が feature ブランチで実装 → CI 自動検証 → 人間がレビュー・マージ → CD で自動デプロイ

#### Issue #17: ノルマ計算ロジックの実装（SP: 2）

- **担当：** Copilot
- **実装内容：**
  - 1日あたりの必要読書ページ数を計算するロジックを実装する
    - 残ページ数 P = target_pages − current_page
    - 残日数 D = 今日を含む残日数（期限当日は D=1）
    - 1日あたりの必要ページ数 N = ⌈P / D⌉（切り上げ）
  - 期限超過時（D ≤ 0）のハンドリングを実装する
  - 一覧画面（W-4）と詳細画面（W-6）に「今日のノルマ」を表示する
  - ノルマ計算の RSpec ユニットテストを作成する

  - 期限当日に D=1 として計算される
  - 期限超過時に適切なメッセージが表示される
