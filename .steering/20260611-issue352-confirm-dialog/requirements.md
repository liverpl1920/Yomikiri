# 要求内容

## 概要
積読本詳細画面の「読了にする！」ボタンをクリックした際に、ブラウザ標準の確認ダイアログを表示して誤操作を防ぐように改善します。

## 背景
現在、詳細画面にある「読了」ボタンをクリックすると、確認なしで即座に読了ステータスへ移行するため、スマホでのスクロール時やPCの誤クリックにより意図しないデータ更新が発生するリスクがあります。安全性を高め、誤操作によるストレスをなくすため確認を挟みます。

## 実装対象の機能

### 1. 読了確認ダイアログ表示
- 「読了にする！」ボタン押下時に「本当に読了にしますか？」という確認ポップアップ（ブラウザのConfirmダイアログ）を表示。
- キャンセルした場合は処理を中断し、画面とステータスを維持。
- OKした場合は従来通りの読了処理を実行。

## 受け入れ条件

### 読了確認ダイアログ
- [x] ボタンクリック時に確認ダイアログが表示されること
- [x] キャンセル時に画面が遷移せず、読了状態にならないこと
- [x] OK時に読了お祝いモーダルが表示されること
