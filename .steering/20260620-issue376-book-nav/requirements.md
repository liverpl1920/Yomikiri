# 要求内容

## 概要

書籍詳細画面（show ビュー）に「前の本へ（＜）」「次の本へ（＞）」ナビゲーションリンクを追加し、一覧画面を経由せずに前後の書籍詳細へ直接遷移できるようにする。

## 背景

現在、ある書籍の詳細画面を見ている際に隣の書籍の詳細を確認したい場合、一度「一覧に戻る」ボタンを押して一覧画面に遷移し、再度目的の書籍を選択する必要があり、UX が煩雑。

## 実装対象の機能

### 1. モデルメソッドの追加

- `Book#prev_book_by_id` — ユーザーの全書籍の中で、ID が小さいもの（前の本）を1件取得
- `Book#next_book_by_id` — ユーザーの全書籍の中で、ID が大きいもの（次の本）を1件取得

> **注意**: 既存の `previous_book` は「同一タイトルの前回読書記録」を指すメソッドであり、
> Issue #376 の「前の書籍」とは異なる。混同しないよう、メソッド名を明確に区別する。

### 2. ビューへのナビゲーション追加

- 書籍詳細画面（`books/show.html.erb`）の `book-show__actions` エリアに「前の本」「次の本」ボタンを追加
- 前後の書籍が存在する場合のみリンクを表示（存在しない場合は非表示またはグレーアウト）

## 受け入れ条件

### モデルメソッド
- [ ] `prev_book_by_id` が、同ユーザーの書籍で id が現在より小さい中で最大のものを返す
- [ ] `next_book_by_id` が、同ユーザーの書籍で id が現在より大きい中で最小のものを返す
- [ ] 最初の書籍の `prev_book_by_id` は `nil` を返す
- [ ] 最後の書籍の `next_book_by_id` は `nil` を返す
- [ ] 他ユーザーの書籍は対象にならない

### ビュー
- [ ] 「前の本」リンク（＜ 前の本）が書籍詳細画面に表示される
- [ ] 「次の本」リンク（次の本 ＞）が書籍詳細画面に表示される
- [ ] 前の本が存在しない場合、「前の本」リンクは非表示
- [ ] 次の本が存在しない場合、「次の本」リンクは非表示

## スコープ外

- 並び順（ステータス別・期限別など）のコンテキスト維持（将来的な拡張として Issue 内でも言及あり）
- ステータスごとのフィルタリング
