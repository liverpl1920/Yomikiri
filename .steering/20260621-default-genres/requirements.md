# 要求内容

## 概要

マイページのジャンル管理機能において、新規ユーザー登録時にアプリ規定のデフォルトジャンル（7種類）を自動登録する機能を追加します。また、既存のユーザーに対してもデフォルトジャンルを登録できる移行用のRakeタスクを用意します。

## 背景

ジャンル設定画面を開いた初期状態が完全に空（未登録）であると、ユーザーは何もない状態からすべて手入力でジャンルを構築しなければならず、利用のハードルが高くなってしまいます。あらかじめ一般的なデフォルトジャンルを自動登録しておくことで、スムーズに本棚の整理やカスタマイズを開始できるようにします。

## 実装対象の機能

### 1. 新規ユーザー登録時のデフォルトジャンル自動登録
- ユーザーアカウントが作成されたタイミング（`after_create`）で、以下のデフォルトジャンルを自動的に登録（`Genre`レコードを生成）します。
  - ビジネス
  - 小説・文学
  - 技術書・専門書
  - 自己啓発
  - エッセイ・読み物
  - 実用書・趣味
  - その他
- 登録されたジャンルは、ユーザーがマイページから自由に「名称変更（編集）」や「削除」を行えるようにします（既存のジャンル編集・削除機能がそのまま利用可能）。

### 2. 既存ユーザー向けのデフォルトジャンル一括登録Rakeタスク
- すでに登録済みの既存ユーザーに対して、デフォルトジャンルを登録するためのRakeタスクを用意します。
- すでにいくつかのジャンルを登録しているユーザーを考慮し、重複しないように登録を行います。

## 受け入れ条件

### ユーザー登録とジャンル自動生成
- [ ] ユーザー新規登録（サインアップ）が完了した際、該当ユーザーの `Genre` レコードとしてデフォルトジャンル（7件）が登録されていること。
- [ ] デフォルトジャンルは「ビジネス」「小説・文学」「技術書・専門書」「自己啓発」「エッセイ・読み物」「実用書・趣味」「その他」の7件であること。
- [ ] マイページのジャンル設定画面に, 登録されたデフォルトジャンルが表示されること。
- [ ] デフォルトジャンルに対して、名称変更（編集）および削除が行えること。

### 既存ユーザー向け一括登録Rakeタスク
- [ ] Rakeタスクを実行した際、ジャンルが未登録の既存ユーザーに対してデフォルトジャンルが正しく登録されること。
- [ ] 既に同名のジャンルが登録されている場合は、二重に作成されない（ユニーク制約エラーにならない）こと。
