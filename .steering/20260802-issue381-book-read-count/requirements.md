# 要求内容

## 概要

読了した本を「もう一度読む（再読）」として新規登録する際、書籍の「読了回数（`read_count`）」をカウントアップして記録し、タイトルの先頭に「【2度目】」「【3度目】」などのプレフィックスを自動付与する機能を実装します。

## 背景

現在、読了した本を「この本をもう一度読む」リンクから再登録する際、過去の本と区別がつかず、何回目の読書であるかの履歴が残らない（あるいは見分けがつかない）状態になっています。
書籍データに読了回数を明示的に持たせ、タイトルに「【N度目】」のプレフィックスを付与して保存することで、読書履歴を視覚的かつデータ構造的に区別できるようにします。

## 実装対象の機能

### 1. `read_count` カラムの追加とデータ移行
- `books` テーブルに `read_count` (integer, default: 0, null: false) を追加します。
- 既存の `completed`（読了）の書籍データの `read_count` を `1` 以上に設定します（複数回読まれている同一書籍は順に 1, 2, 3... と設定）。

### 2. 読了時の `read_count` 自動設定
- 初回登録時（最初から読了状態で登録）または途中で `completed` に変更された場合、`read_count` が `0` であれば `1` に設定します。

### 3. 再読（もう一度読む）新規登録時の挙動拡張
- コピー元の本から新規作成画面（`new`）に遷移する際、`read_count` をコピー元の `read_count + 1` に設定します。
- コピー元のタイトルから古いプレフィックス（`【N度目】`）を除去した上で、新しいプレフィックス（`【N度目】`）を先頭に自動付与します（`read_count` が 2 以上の場合）。
- 新規登録フォームにプレフィックス付きのタイトルと更新された `read_count`、初期化されたステータス（未読・現在ページ0）が設定された状態で表示します。

### 4. タイトルの正規化と同一本判定の維持
- `Book.normalize_title` メソッドでタイトル先頭の `【N度目】` を除去してから正規化するように修正し、重複タイトル警告や過去の読書履歴へのナビゲーション機能が正しく動作し続けるようにします。

### 5. 画面表示の整合
- 既存の `display_title` で動的に `(N回目)` を付与していた挙動を廃止し、DBに保存されたタイトルをそのまま表示します。

## 受け入れ条件

### `read_count` とタイトルの付与
- [ ] 本を未読で登録した時、`read_count` は `0` であること。
- [ ] 本を読了（`completed`）にした時、`read_count` が `0` ならば `1` に更新されること。
- [ ] 読了した本（例: `read_count: 1`, タイトル: `プログラミングRuby`）の詳細画面から「この本をもう一度読む」を押した際、遷移した新規登録画面のタイトル初期値が `【2度目】プログラミングRuby` になっており、`read_count` が `2` に設定されていること。
- [ ] 再読本（例: `read_count: 2`, タイトル: `【2度目】プログラミングRuby`）からさらに「この本をもう一度読む」を押した際、新規登録画面のタイトル初期値が `【3度目】プログラミングRuby` になっており、`read_count` が `3` に設定されていること。
- [ ] 新規登録画面からそのまま登録すると、プレフィックス付きのタイトルで保存され、一覧や詳細画面で `【2度目】プログラミングRuby` と表示されること。

### 重複・ナビゲーションの維持
- [ ] タイトルにプレフィックスが付いていても、`normalized_title` はプレフィックスなしのタイトルとして保存されること（例: `【2度目】プログラミングRuby` の `normalized_title` は `プログラミングruby`）。
- [ ] 詳細画面の「前回（N回目）の読書記録はこちら」リンクがプレフィックス付き書籍間でも正しく表示され、以前の周回の書籍詳細画面に遷移できること。

## 成功指標
- すべての受け入れ条件を満たし、関連するRSpecテストが全て通過すること。

## スコープ外
- 今回は「もう一度読む」ボタンを介さずに、ユーザーが直接手動でタイトルに `【2度目】` などと入力して登録した際の `read_count` 自動判定は行いません（フォーム初期値の制御と、コピー時のカウントアップに限定します）。
