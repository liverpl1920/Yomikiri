# 要求内容

## 概要
メモ機能における太字や文字色などの書式設定（装飾機能）を削除し、プレーンテキストでの入力および表示に変更します。

## 背景
- メモをより軽量かつサクサクと入力できるようにするため。
- UI全体の統一感を保ち、不要な装飾による複雑さを排除するため。

## 実装対象の機能

### 1. メモフォームからのツールバー削除と通常のtextareaへの変更
- 書籍詳細画面 (`books/show.html.erb`)、メモ編集画面 (`book_memos/edit.html.erb`)、メモ作成時の Turbo Stream (`book_memos/create.turbo_stream.erb`) のそれぞれから、太字・色指定などの装飾ツールバーを削除します。
- `f.text_area` の `data` 属性等から Stimulus コントローラー `memo-format` の記述を削除します。

### 2. メモ表示時に装飾を適用せずプレーンテキストとして表示
- 過去に登録されたメモも含め、`**強調**` などのマークアップは HTML タグに変換せず、そのままプレーンテキストとして表示します。
- 改行は `simple_format` を使って正しく反映されるようにし、HTML タグが含まれている場合は安全にエスケープ（サニタイズ）します。

### 3. 不要な Stimulus コントローラーの削除
- 装飾機能のために使用されていた `memo_format_controller.js` を削除します。

### 4. 関連テストの修正
- `BookMemosHelper` の仕様変更に伴い、`book_memos_helper_spec.rb` をプレーンテキスト出力向けに修正します。

## 受け入れ条件
- [ ] 書籍詳細画面でメモを入力する際、太字や文字色を適用するための装飾用ツールバーが表示されないこと。
- [ ] メモ編集画面でも、同様に装飾用ツールバーが表示されないこと。
- [ ] 既に `**強調**` や `[color=#ff0000]赤色[/color]` といった文字が含まれるメモを表示した際、装飾されずにそのままのテキストとして表示されること。
- [ ] `<script>` などの HTML タグが入力された場合は、安全にエスケープされて表示されること。
- [ ] rspec テストがすべてパスすること。
