# 要求内容

## 概要

書籍詳細画面（W-6）に「削除する」ボタンを追加し、削除確認モーダル（W-12）を実装して、積読本を削除できる機能を提供する。

## 背景

GitHub Issue #17「積読削除機能の作成」の要求に基づき、ユーザーが不要になった積読本を削除できるようにする。削除前に確認モーダルを表示することでの誤削除を防止する。

## 実装対象の機能

### 1. 削除ボタンの追加（W-6：書籍詳細画面）
- 書籍詳細画面の操作エリアに「削除する」ボタンを追加
- ボタンクリックで削除確認モーダルを表示する

### 2. 削除確認モーダル（W-12）
- 対象書籍名を表示する
- 確認メッセージを表示する（「この本を削除してもよろしいですか？」）
- 「削除する」ボタン：書籍を削除し、積読一覧画面（W-4）へリダイレクト
- 「キャンセル」ボタン：モーダルを閉じて書籍詳細に戻る

### 3. BooksController#destroy アクション
- 認証済みユーザーの書籍のみ削除可能
- 削除後、積読一覧画面（W-4 /books）へリダイレクト

## 受け入れ条件

### 削除ボタン
- [ ] 書籍詳細画面に「削除する」ボタンが表示される

### 削除確認モーダル
- [ ] 「削除する」ボタンをクリックするとモーダルが表示される
- [ ] モーダルに対象書籍名が表示される
- [ ] 「削除する」で書籍が削除され、一覧画面へリダイレクトされる
- [ ] 「キャンセル」でモーダルが閉じる

### セキュリティ
- [ ] 未ログイン時はログイン画面へリダイレクト
- [ ] 他ユーザーの書籍は削除できない（404）

## スコープ外

- ソフトデリート（論理削除）は実装しない
- 削除後のアンドゥ機能は実装しない
