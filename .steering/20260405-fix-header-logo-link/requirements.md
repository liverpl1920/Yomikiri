# 要求内容

## 概要

ヘッダーの「Yomikiri」ロゴリンクを、ログイン状態に応じて遷移先を切り替えるバグ修正。

## 背景

現在のヘッダーロゴは常に `root_path（/）` へリンクしているため、ログイン済みユーザーがロゴをクリックしても積読一覧画面（`/books`）に遷移できない。ログイン後の主要なランディングページは積読一覧であるため、ロゴクリックでその画面に戻れるべきである。

## 実装対象の機能

### 1. ヘッダーロゴリンク先の動的切り替え

- ログイン済み（`user_signed_in? == true`）の場合: `books_path（/books）` へ遷移
- 未ログイン（`user_signed_in? == false`）の場合: `root_path（/）` へ遷移（現状維持）

## 受け入れ条件

### ヘッダーロゴリンク
- [x] ログイン状態でロゴをクリックすると `/books` に遷移する
- [x] 未ログイン状態でロゴをクリックすると `/` に遷移する
- [x] ログイン・未ログインいずれの場合もロゴテキスト「Yomikiri」と CSS クラスは変化しない

## 成功指標

- ヘッダーロゴリンクのリクエストスペックが全件パスする
- RuboCop オフェンスがゼロ

## スコープ外

以下はこのフェーズでは実装しません:

- ヘッダーのその他デザイン変更
- フッターの変更
- ロゴ画像の追加
