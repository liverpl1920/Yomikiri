# 要求内容

## 概要

マイページ（W-8）を作成し、ユーザー情報・読書実績の表示とニックネームのインライン編集機能を提供する。

## 背景

ユーザーが自分のプロフィール情報や読書進捗を一覧確認でき、ニックネームを自由に編集できる場所が必要。
現在のヘッダーの「マイページ」リンクは Devise のデフォルトアカウント編集ページに繋がっているため、専用のマイページを実装する。

## 実装対象の機能

### 1. マイページ表示
- ユーザー情報を表示（ニックネーム（未設定時はメールアドレス）・登録日・メールアドレス）
- 読書実績を表示
  - 読了冊数（status = completed の books 数）
  - 総読了ページ数（completed な books の target_pages 合計）
  - 連続読書日数（books.updated_at を日付集計して算出する簡易実装）
- 読了履歴リストを表示（completed_at 降順）
- アカウント設定リンク（パスワード変更）を配置
- 「一覧に戻る」ボタンを配置

### 2. ニックネーム編集
- インラインフォームでニックネームを設定・更新
- 未設定時はメールアドレスをフォールバック表示
- 最大50文字のバリデーション

### 3. ヘッダー更新
- ヘッダーのドロップダウンメニューの「マイページ」リンクを新マイページパスに変更

## 受け入れ条件

### マイページ表示
- [ ] マイページにユーザー情報が正しく表示される
- [ ] ニックネーム未設定時はメールアドレスが表示される
- [ ] 読書実績（読了冊数・総読了ページ数・連続読書日数）が正しく表示される
- [ ] 読了履歴リスト（completed_at 降順）が表示される
- [ ] 「一覧に戻る」ボタンで積読一覧に戻れる

### ニックネーム編集
- [ ] ニックネームを設定・更新できる
- [ ] バリデーションエラー時にエラーが表示される

### ヘッダー
- [ ] ヘッダーのドロップダウンメニューからマイページへ遷移できる

## スコープ外

- パスワード変更機能（Issue #28 で実装）
- メールアドレス変更機能（別 Issue）
- アバター画像のアップロード
