# 要求内容

## 概要

読書統計ページ（`/mypage/stats`）に表示されている「ジャンル別読書ポートフォリオ」を、新設された書籍の「種類（媒体形式/`Book.categories`）」ごとの統計「種類別読書ポートフォリオ」に変更します。また、表示位置を「書籍別の読了ページ内訳」の直下へ移動し、グラフ形式を一目で比率が把握しやすい「円グラフ（ドーナツチャート）」に変更します。

## 背景

データ構造の変更により、書籍に「種類（`category`）」が定義されました。これに伴い、従来のフリー入力に近い「ジャンル」よりも、固定値定義された「種類」別にポートフォリオを可視化する方が、ユーザーが自身の読書傾向（技術書、漫画、純文学など）をより直感的に割合として捉えやすくなります。また、レイアウトやグラフのビジュアル（円グラフ化）を最適化し、より洗練された統計体験を提供します。

## 実装対象の機能

### 1. 種類別統計データ集計
- `ReadingReportSummaryService` の `genres` 集計処理を `categories` 集計処理に切り替えます。
- 集計対象の期間内に記録された `ReadingLog` のページ数を、関連する `Book` の `category` ごとにグループ化し、合計読了ページ数および割合を算出します。
- `Book` モデルに日本語ローカライズ用の `categories_i18n` クラスメソッドを実装し、グラフのラベルや凡例に日本語の名称を表示します。

### 2. レイアウトの最適化
- 統計ページにおいて、対象グラフの表示順序を以下のように並び替えます。
  1. 日別読了ページ数
  2. 書籍別の読了ページ内訳
  3. **種類別読書ポートフォリオ（★本機能）**
  4. 読書ログ詳細

### 3. 円グラフ（ドーナツチャート）表示
- `chartkick` などの外部ライブラリを新規導入せず、軽量でカスマイズ性の高い CSS `conic-gradient` を使用した円グラフ（中央を白く抜いたドーナツチャート）を HTML/CSS で実装します。
- グラフの右側（スマホ表示時は下側）にカラー凡例と、カテゴリごとの読了ページ数・パーセンテージを一覧表示します。

## 受け入れ条件

### 種類別統計データ集計
- [ ] `ReadingReportSummaryService` の返り値に `categories` キーが含まれ、`genre` の代わりに `category` ごとのデータが格納されていること。
- [ ] 各カテゴリのデータには、日本語名 (`name`)、読了ページ数 (`pages_read`)、割合 (`ratio`、小数点以下第一位)、enum キー (`key`) が含まれていること。
- [ ] `Book.categories_i18n` が、ロケール定義ファイル `ja.yml` から各種類（`other`, `literature`等）の日本語訳を正しく取得できること。

### レイアウトおよび円グラフ表示
- [ ] 統計ページで「種類別読書ポートフォリオ」が「書籍別の読了ページ内訳」のすぐ下に移動していること。
- [ ] 棒グラフではなく、円形（ドーナツ型）のグラフが表示されていること。
- [ ] 凡例と各カテゴリの読了ページ数および比率が正しく並んで表示されていること。

## 成功指標
- ユーザーが統計ページを開いた際、自身が読んだ本が「どの種類（技術書や漫画など）に偏っているか」をドーナツグラフによって一目で把握できること。
- プレミアムなデザインを崩さず、レスポンシブにも美しく表示されること。

## スコープ外
- 「種類」の新規追加や編集（固定定義値のため）。
- 既存の「ジャンル」データの完全な削除（今回は統計ページでの表示のみをジャンルから種類に変更します）。
