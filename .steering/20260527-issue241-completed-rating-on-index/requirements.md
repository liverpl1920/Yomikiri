# 要求内容

## 概要

一覧画面で読了済みの本に評価（★）を表示できるようにし、読書履歴の比較と振り返りをしやすくする。

## 背景

- 現状、評価は詳細画面でのみ確認でき、一覧から読了本の良し悪しを俯瞰しにくい。
- Issue #241 の要件として「読了本の評価表示」「未読/読書中は既存仕様維持」「未設定時ルール明確化」が求められている。

## 実装対象の機能

### 1. 一覧カードでの読了本評価表示
- 読了済み（`status: completed`）の書籍カードに評価表示欄を追加する。
- 表示形式は既存詳細画面の仕様に合わせ、`★` を評価点（1-5）分だけ表示する。

### 2. 評価未設定時の表示ルール適用
- 読了済みでも評価が未設定（`rating: nil`）の場合は評価欄を表示しない。
- 未読/読書中は従来通り評価欄を表示しない。

## 受け入れ条件

### 一覧カードでの読了本評価表示
- [x] `books#index` の一覧で、読了済みかつ評価ありの本に `★` が表示される。
- [x] `★` の個数が `rating` の値（1-5）と一致する。
- [x] 既存のカード情報（タイトル、ステータス、期限/読了日、進捗など）の表示が崩れない。

### 評価未設定時の表示ルール適用
- [x] 読了済みでも `rating` が未設定なら評価表示は出ない。
- [x] 未読/読書中の本には評価表示が出ない。

## 成功指標

- 一覧画面だけで読了本の評価比較が可能になる。
- 既存一覧機能の回帰不具合が発生しない（関連Request/System specがパス）。

## スコープ外

以下はこのフェーズでは実装しない:

- 評価の入力UI変更（詳細画面の評価入力フォーム改修）
- 評価でのソート/絞り込み機能追加
- 評価表示デザインの大幅改修（既存カードレイアウトの全面変更）
