# 機能要件: 積読詳細画面に、書籍情報を引き継いで再登録できる「この本をもう一度読む（コピー作成）」ボタンを追加する

## 1. 概要
過去に読了した本や既存の積読本と同じ本を「もう一度読み直したい（再読したい）」場合に、ユーザーが再度タイトルや著者名、総ページ数などを手入力する手間を省くための機能です。

## 2. ユーザーシナリオ
1. ユーザーは積読または読了した本の詳細画面（`books/show`）を開く。
2. 詳細画面のアクションエリア（一覧に戻るなどのボタン群）に配置された「この本をもう一度読む」ボタンをクリックする。
3. 新規登録画面（`books/new`）に遷移し、元の本から引き継がれた情報（タイトル、著者名、総ページ数、ジャンル、出版社、翻訳者、書影URL/画像、ISBN）がフォームに初期入力された状態となる。
4. ステータスは「未読」、読んだページ数は 0 にリセットされており、期限やメモ・評価は引き継がれない。
5. ユーザーは新たな読了期限を設定して登録ボタンをクリックするだけで、2回目の読書記録（積読）を簡単に開始できる。

## 3. 機能要件詳細
- **詳細画面（showビュー）**:
  - `book-show__actions` 内に「この本をもう一度読む」リンク（ボタン）を表示する。
  - リンク先は `new_book_path(copy_from_id: @book.id)` とする。
- **新規登録画面（newアクション）**:
  - `params[:copy_from_id]` が指定されている場合、現在のユーザー（`current_user`）に紐づく該当書籍を取得する。
  - 該当書籍が存在する場合、`.dup` を用いて複製モデルインスタンスを作成する。
  - 複製インスタンスの属性から以下をリセットまたは初期化する：
    - `status`: `:unread` （未読）
    - `current_page`: 0 （読んだページ数）
    - `extension_count`: 0 （延長回数）
    - `deadline`: `nil` （読了期限）
    - `completed_at`: `nil` （読了日時）
    - `memo`, `memo_updated_at`: `nil` （コメント・メモ）
    - `rating`, `review`: `nil` （評価・感想）
  - 元の書籍に Active Storage の `cover_image` がアタッチされている場合は、複製インスタンスにも同じ blob をアタッチする。
  - 他のユーザーの書籍IDや、存在しない書籍IDが `copy_from_id` パラメータとして渡された場合は、安全にフォールバックして通常の空の新規登録画面（`current_user.books.build`）を表示する。

## 4. セキュリティ要件
- 自身の所有していない書籍のID（`copy_from_id`）を指定された場合に、情報漏洩や不正なコピーが発生しないよう、取得範囲を `current_user.books` に限定する。
