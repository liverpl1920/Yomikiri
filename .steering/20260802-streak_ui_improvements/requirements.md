# 要求内容

## 概要

読書ストリーク（連続読書記録）の表示において、数値のみや曖昧な表記になっている箇所をUI改善し、数値の横に「日連続」または「日」といった単位を明確に追記・デザイン調整することで、ユーザーが直感的に理解できるようにする。

## 背景

現在、ダッシュボードやマイページなどで表示されている「読書ストリーク」の表示が数値のみ（例: 「7」）または単位が曖昧なため、ユーザーが初見で何の数字（何日連続で読書できているのか）を理解しづらい。視認性向上のため、数値の強調と単位の明記を行う。

## 実装対象の機能

### 1. 多言語化定義（ja.yml, en.yml）の拡張
- 読書ストリーク数の単位（日、日連続、days、days streak）のロケールキーを定義する。
- ストリークが 0 の場合は「0 日」、1 以上の場合は「7 日連続」と切り替えられるように定義する。

### 2. ダッシュボードの読書ストリーク表示改善
- `app/views/dashboards/show.html.erb` での表示を、数値部分を大きく強調し、単位（日連続、日）は少し小さめのフォントサイズで添えるように修正。
- 単位は多言語化定義から取得する。

### 3. マイページの連続読書日数表示改善
- `app/views/mypages/show.html.erb` での表示を、数値部分を大きく強調し、単位（日連続、日）は少し小さめのフォントサイズで添えるように修正。
- 単位は多言語化定義から取得する。

### 4. スタイリング（CSS）の調整
- `app/assets/stylesheets/dashboards.css` と `app/assets/stylesheets/mypages.css` に、単位（unit）表示用のスタイルを追加し、メリハリのあるデザインにする。

## 受け入れ条件

### ダッシュボードの読書ストリーク
- [ ] 読書ストリークが 1 以上のときに「X 日連続」と表示されること。
- [ ] 読書ストリークが 0 のときに「0 日」と表示されること。
- [ ] 数値（大きく強調）と単位（少し小さめ）がメリハリのあるデザインで表示されること。

### マイページの連続読書日数
- [ ] 連続読書日数が 1 以上のときに「X 日連続」と表示されること。
- [ ] 連続読書日数が 0 のときに「0 日」と表示されること。
- [ ] 数値（大きく強調）と単位（少し小さめ）がメリハリのあるデザインで表示されること。

## 成功指標
- ユーザーがダッシュボードやマイページを見た際に、読書ストリークの進捗状態を直感的に把握できること。

## スコープ外

以下はこのフェーズでは実装しません:
- 読書ストリークの集計ロジック自体の変更
