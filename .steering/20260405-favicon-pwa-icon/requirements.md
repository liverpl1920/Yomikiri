# 要求内容

## 概要

ブラウザのファビコンとPWAアイコンが Rails デフォルトの赤い四角のままになっている問題を修正し、Yomikiriブランドに合った「Y」ロゴアイコンに置き換える。

## 背景

`rails new` 時に自動生成されたプレースホルダーファイルがそのまま残っており、ユーザーがブラウザのタブやPWAとしてホーム画面に追加した際に赤い四角が表示されてしまう。Yomikiriらしいブランドアイデンティティを確立するために独自アイコンへの差し替えが必要。

## 実装対象の機能

### 1. SVGアイコンの差し替え

- `public/icon.svg` を Yomikiri ブランドデザイン（青背景 #2563eb に白の「Y」）に変更
- ブラウザタブのファビコンとして表示される

### 2. PNGアイコンの差し替え

- `public/icon.png` を SVG と同等デザインの 512×512 PNG に変更
- PWA としてホーム画面に追加した際のアイコンとして使用

### 3. PWA マニフェストの修正

- `app/views/pwa/manifest.json.erb` の `theme_color`、`background_color`、`description` を Yomikiri に適した値に更新

## 受け入れ条件

### SVGアイコン
- [ ] `public/icon.svg` が青背景（#2563eb）に白い「Y」を描画したデザインになっている
- [ ] `<rect fill="red"/>` の記述が削除されている

### PNGアイコン
- [ ] `public/icon.png` が 512×512 ピクセルの独自デザインになっている
- [ ] 赤い四角のプレースホルダーではない

### PWA マニフェスト
- [ ] `theme_color` が `"#2563eb"` になっている
- [ ] `background_color` が `"#ffffff"` になっている
- [ ] `description` が `"積読を消化する技術 — 読了期限とノルマで読書を行動に変えるアプリ"` になっている

## スコープ外

以下はこのフェーズでは実装しません:

- 複数サイズのアイコン（16px, 32px, 192px など）の追加
- Apple Touch Icon の追加
- 動的なアイコン生成
