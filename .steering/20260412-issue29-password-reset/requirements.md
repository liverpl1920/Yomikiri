# 要求内容

## 概要

W-9（パスワード再設定）からW-14（パスワード変更）までのメール経由フローを実装する。
ログイン画面の「パスワードを忘れた場合」リンクから始まり、メール送信 → リンク経由でパスワード変更 → ログイン画面へリダイレクトする一連のフローを完成させる。

## 背景

Issue #8（Devise導入とUserモデル作成）でDeviseの `:recoverable` モジュールは追加済みだが、
パスワード再設定ビューの実装、カスタムPasswordsコントローラー、本番環境のActionMailer/SendGrid設定が未実装のため、機能が使えない状態になっている。

## 実装対象の機能

### 1. パスワード再設定リクエスト画面（W-9）
- メールアドレス入力フォームを表示する
- 「再設定メールを送信」ボタンを実装する
- 「ログイン画面に戻る」リンクを配置する

### 2. パスワード変更画面（W-14）
- メール内のリンクから遷移してくる
- 新しいパスワード・確認用パスワードの入力フォームを表示する
- 変更完了後にログイン画面（W-3）へリダイレクトする

### 3. カスタムPasswordsコントローラー
- Devise::PasswordsControllerを継承して作成
- パスワード変更後のリダイレクト先をカスタマイズする

### 4. 本番環境ActionMailer/SendGrid設定
- `config/environments/production.rb` にSMTP設定を追加する
- `SENDGRID_API_KEY` 環境変数を利用する
- Deviseのmailer_senderを適切なアドレスに更新する

## 受け入れ条件

### パスワード再設定フロー
- [ ] ログイン画面の「パスワードを忘れた場合」リンクからW-9へ遷移できる
- [ ] W-9でメールアドレスを入力して送信するとDevise経由で再設定メールが送信される
- [ ] メール内のリンクからW-14へ遷移できる
- [ ] W-14で新しいパスワードを入力して変更完了後、ログイン画面へリダイレクトされる

### メール配信（本番）
- [ ] production.rbにSendGrid SMTP設定が追加されている
- [ ] `SENDGRID_API_KEY` 環境変数から認証情報を取得する

## スコープ外

- Deviseの確認メール（:confirmable）機能の実装
- カスタムメールテンプレートのデザイン変更（Deviseデフォルトを使用）
- SendGrid APIキーの実際の登録作業（インフラ作業のため）
