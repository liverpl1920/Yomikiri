# 要件定義 (Issue #324)

## 概要
ユーザーが過去に読んだ本を視覚的かつ直感的に楽しく振り返られるよう、ダッシュボードの「過去の読了本の振り返り」エリアにおいて、対象の本の「書影（カバー画像）」も合わせて表示する。

## 詳細な要件
1. **書影の表示**:
   - ダッシュボードの「過去の読了本の振り返り」カード (`.lookback-card`) 内に、本に紐づく書影（カバー画像）を表示する。
   - 表示には既存の `BooksHelper#book_cover_src` ヘルパーを活用する。
2. **レイアウト**:
   - PCなどの十分な画面幅がある環境では、左側に書影、右側にタイトルや評価、感想、メモを並べる横並び（Flexbox等）とする。
   - レスポンシブ対応として、画面幅が狭い場合（例: 540px以下）は縦並びにするなど、デザインが崩れないようにする。
3. **フォールバック**:
   - 書影がない場合、または何らかの理由で取得できない場合は、デザインが崩れないように「No Image」用のプレースホルダーを表示する。
4. **CSS規約**:
   - Tailwind CSSは使用せず、リポジトリの規約に従って BEM 命名規則の Vanilla CSS を `app/assets/stylesheets/dashboards.css` に実装する。
