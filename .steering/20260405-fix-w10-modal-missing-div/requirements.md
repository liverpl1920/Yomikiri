# 要求内容

## 概要

`app/views/books/show.html.erb` の期限延長モーダル（W-10）で、`form_with` の終了後に `.modal` および `.modal-overlay` の closing `</div></div>` が欠落しているバグを修正する。

## 背景

W-10（期限延長モーダル）の `form_with` ブロック終了後に `</div></div>` が不足しており、W-13（読了お祝いモーダル）が W-10 モーダルの内部に DOM ネストされてしまっている。ブラウザのHTMLパーサーが暗黙的に修正することが多いが、Stimulus の `modal` コントローラーの動作やCSSによる表示に意図しない副作用を引き起こす可能性がある。

## 実装対象の機能

### 1. W-10 モーダルの DOM 構造修正

- `form_with` 終了タグ `<% end %>` の直後に `</div>` (`.modal` の閉じタグ) と `</div>` (`.modal-overlay` の閉じタグ) を追加する
- W-13（読了お祝いモーダル）が W-10 モーダルの外側に配置される正しい DOM 構造にする

## 受け入れ条件

### W-10 モーダル DOM 修正

- [ ] `form_with` の `<% end %>` の直後に `</div></div>` が存在する
- [ ] W-13 モーダルが W-10 モーダルの外部に配置されている
- [ ] 期限延長モーダルが正常に開閉できる
- [ ] 読了お祝いモーダルが正常に表示される

## 成功指標

- W-10 / W-13 の DOM ネストが解消される
- Stimulus の `modal` コントローラーが意図通りに動作する

## スコープ外

- モーダルのスタイル変更
- Stimulusコントローラーのロジック変更
- テストの追加（HTMLのタグ欠落修正のみ）
