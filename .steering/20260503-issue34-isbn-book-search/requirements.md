# 要求内容

## 概要

書籍登録フォームに「ISBNまたは書籍名」で書籍を検索し、openBD / Google Books APIから書籍情報を自動補完する機能を追加する。

## 背景

毎回タイトル・著者・ページ数を手入力するのは手間がかかる。ISBNが手元にある場合はワンタッチで、書籍名しか分からない場合は候補一覧から選択して情報を補完できるようにする。

## 実装対象の機能

### 1. ISBN検索による自動補完
- ISBN（10桁または13桁、ハイフン有無問わず）を入力して検索ボタンを押すと openBD API で書籍情報を取得する
- 取得した情報（タイトル・著者・総ページ数・書影URL）をフォームに自動入力する

### 2. 書籍名検索による候補表示・選択
- ISBN以外のテキストを入力して検索ボタンを押すと Google Books API で候補を取得する
- 最大5件の候補をリスト表示する
- 候補をクリックするとフォームに自動入力される

### 3. 書影URLの自動補完
- ISBNが判明している場合は `https://cover.openbd.jp/{ISBN13}.jpg` を書影URLフィールドに自動セットする
- ISBN不明の場合はフィールドを空のまま

## 受け入れ条件

### ISBN検索
- [ ] 13桁のISBNを入力して検索すると書籍情報がフォームに補完される
- [ ] 10桁のISBNでも動作する
- [ ] ハイフン区切りのISBN（978-4-...）でも動作する
- [ ] openBDに存在しないISBNの場合「該当する書籍が見つかりませんでした」が表示される

### 書籍名検索
- [ ] 書籍名で検索すると候補一覧が表示される
- [ ] 候補をクリックするとフォームに情報が補完される
- [ ] 候補が0件の場合「該当する書籍が見つかりませんでした」が表示される

### 共通
- [ ] 検索中は「検索中...」表示でフィードバックが得られる
- [ ] 自動補完後もフォームの各フィールドは手動で編集できる
- [ ] ネットワークエラー時に適切なメッセージが表示される
- [ ] Enterキーで検索が実行される

## スコープ外

- 書影URLの存在確認（openBDに画像がない場合のフォールバック）
- 過去の検索履歴の保持
- ページング（最大5件固定）
- Google Books以外のタイトル検索エンドポイント
