# 要求内容

## 概要

GitHub issue #286 に基づき、書籍詳細画面の進捗記録方法を「現在ページを直接入力」だけにする。

## 背景

ユーザーは「今日読んだページ数」を相対的に把握していないことが多い。現在どのページまで読んだかを入力する方式に絞ることで、詳細画面で直感的に進捗を記録できるようにする。

## 実装対象の機能

### 1. 詳細画面の進捗フォーム整理
- 「今日読んだページ数」入力フォームを削除する。
- 「現在ページ」入力フォームを折りたたみではなく通常表示にする。

### 2. 進捗更新処理の直接入力化
- 詳細画面から送信される `direct_page` で現在ページを更新する。
- 読書ログは従来どおり、更新前後の差分が正の場合のみ記録する。

## 受け入れ条件

- [ ] 詳細画面に「今日読んだページ数」入力が表示されない。
- [ ] 詳細画面に「現在ページ」入力が表示され、更新できる。
- [ ] `direct_page` が不正な場合はエラーになり、現在ページが変わらない。
- [ ] 進捗更新時の読書ログが差分ページ数で記録される。

## スコープ外

- 読書ログ集計やグラフ仕様の変更。
- 一覧画面やマイページの表示仕様変更。
