# Requirements: タイトル入力中オートコンプリート機能 (Issue #188)

## 概要

積読登録画面でタイトルを入力している途中に該当する本を候補表示し、選択で書誌情報を補完できるようにします。

## 背景

手入力だけでは登録に時間がかかるため、入力中に候補を提示して選択できる体験を提供し、登録の操作負荷を下げます。

## 機能要件

### コア機能
1. タイトル入力欄にオートコンプリートUIを追加
2. 入力に対してデバウンス付き（300ms）で検索APIを呼び出す
3. 候補にタイトル・著者・書影の要約情報を表示
4. 候補選択でタイトル/著者/ページ数/書影などをフォームへ反映
5. 候補なし・通信エラー時のフォールバック表示を実装
6. キーボード操作（上下/Enter/Esc）に対応

### 完了条件
- タイトル入力途中で候補が表示される
- 候補選択でフォームが正しく補完される
- 連続入力時に不要なAPI呼び出しが抑制される
- 候補なし/エラー時でも入力継続が可能
- 既存のISBN検索・タイトル検索フローに回帰がない

## テスト要件
- request spec: 検索APIのレスポンスとエラー系を検証
- system spec: 候補表示・選択・キーボード操作を検証

## 技術スタック
- Stimulus.js (Hotwire) でインタラクティブUI実装
- 既存の `/books/search` API エンドポイントを流用
- BEM命名規則でCSSを追加
