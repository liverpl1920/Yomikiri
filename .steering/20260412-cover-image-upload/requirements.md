# 要求定義: 書影アップロード機能 (Issue #26)

## 概要
書籍登録・一覧・詳細画面に書影アップロード・表示機能を追加する。

## 対応画面
- W-5（書籍登録フォーム）
- W-4（積読一覧）
- W-6（書籍詳細）

## 機能要件

### FR-1: 書籍登録フォームへの書影アップロードフィールド追加
- 書籍登録フォーム（W-5）に画像アップロードフィールドを追加する
- ファイル選択UIを提供する

### FR-2: Book モデルへの Active Storage アタッチメント設定
- `Book` モデルに `has_one_attached :cover_image` を追加する

### FR-3: プレースホルダー表示
- 書影が未設定の場合、プレースホルダー（絵文字またはデフォルト画像）を表示する

### FR-4: 一覧画面・詳細画面への書影表示
- W-4（積読一覧）の各カードに書影を表示する
- W-6（書籍詳細）に書影を表示する

### FR-5: 画像バリデーション
- ファイルサイズ: 最大 5MB
- ファイル形式: JPEG, PNG, GIF, WebP のみ許可

## 完了条件
- [ ] 書籍登録時に書影画像をアップロードできる
- [ ] アップロードした書影が一覧画面・詳細画面に表示される
- [ ] 未設定時にプレースホルダーが表示される
- [ ] 本番環境（Render + Amazon S3）でも正常動作する
