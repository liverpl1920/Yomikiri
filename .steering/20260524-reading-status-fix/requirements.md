# 要件: 一覧画面の読書状態表示修正（#224）

## 背景
- 現状、読書済みページがある本（current_page > 0）でも「未読」と判定されるケースがある
- 新規作成時に `current_page > 0` を設定すると、`auto_set_reading_status` が `persisted?` チェックで早期リターンするため、status が `unread` のまま保存される
- ユーザーの実態と表示状態が一致せず、進捗把握に誤解が生じる

## 要件
1. 新規登録時に `current_page >= 1` の場合、ステータスを `reading`（読書中）に自動設定する
2. 一覧画面で `current_page >= 1` の本は「読書中」と表示される
3. `current_page = 0` の本のみ「未読」と表示される
4. 既存の `completed` ステータス表示に回帰不具合がない
5. 新規登録時に `current_page >= 1` の場合、読了期限（deadline）を必須にする

## 完了条件
- 読了ページ数が 1 以上の新規登録本は一覧で「読書中」と表示される
- 読了ページ数が 0 の本は一覧で「未読」と表示される
- 既存の状態表示（読了など）に回帰不具合がない
- RSpec・RuboCop が全通過する
