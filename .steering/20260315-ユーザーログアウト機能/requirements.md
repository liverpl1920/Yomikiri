# 要求仕様: ユーザーログアウト機能（Issue #7 / Project #10）

## 概要

ログインユーザーがヘッダーのドロップダウンメニューからログアウトできる機能を実装する。

## 要求内容

### 機能要求

| # | 要求 | 優先度 |
|---|------|--------|
| F-1 | ヘッダーのドロップダウンにログアウトボタンを配置する | 必須 |
| F-2 | ログアウトボタン押下でセッションを正常に破棄する | 必須 |
| F-3 | ログアウト後にTOPページ（W-1）へリダイレクトする | 必須 |
| F-4 | 未ログイン時はログアウトボタンを表示しない | 必須 |

### 完了条件

- [ ] ログアウトボタン押下でセッションが破棄される
- [ ] ログアウト後にTOPページへリダイレクトされる
- [ ] セッションが正常に破棄される（ログアウト後にユーザー情報にアクセスできない）

## 現状の実装

以下はすでに実装済みの内容:

- `app/views/shared/_header.html.erb`: ドロップダウンにログアウトボタンが存在する
  - `button_to 'ログアウト', destroy_user_session_path, method: :delete`
- `app/controllers/users/sessions_controller.rb`: Devise SessionsController を継承
  - `after_sign_in_path_for` は定義済み
  - **`after_sign_out_path_for` は未定義（要実装）**

## 未実装項目

1. `after_sign_out_path_for` を `Users::SessionsController` に追加してTOPページへのリダイレクトを明示する
2. ログアウトに関するリクエストスペックを充実させる（リダイレクト先の検証）
3. フラッシュメッセージ（「ログアウトしました」）の表示確認
