# 要求内容

## 概要

Issue #15: 積読一覧表示機能（W-4画面）の実装。ログイン後の最初の画面として、ログインユーザーの積読本を一覧表示する。

## 背景

ユーザーが積読登録した書籍の一覧を確認し、本の進捗状況・今日のノルマを把握することで、読書を行動に変えるきっかけを提供する。

## 実装対象の機能

### 1. 書籍一覧表示
- ログインユーザーの積読本を期限が近い順にソートして表示
- 読了済みの本はリスト最下部に表示（未読・読書中→読了の順）
- 未ログインユーザーはログイン画面へリダイレクト

### 2. 書籍カード
- タイトル・読了期限・進捗率・今日のノルマを表示
- 書影は未設定時にプレースホルダー画像を表示
- 賞味期限ビジュアライザー：期限が近づくほど書影が色褪せる
  - 7日以下: sepia弱
  - 3日以下: sepia中
  - 1日以下: sepia強

### 3. ナビゲーション・Empty State
- 「+ 本を追加する」ボタン（書籍登録へ遷移）
- 書籍カードクリックで書籍詳細画面（W-6）へ遷移
- 0冊時はEmpty State（「最初の本を登録して始める」CTA）を表示

### 4. ログイン後リダイレクト
- ログイン後は books_path（積読一覧）へリダイレクト

## 受け入れ条件

### 書籍一覧表示
- [ ] 積読一覧が期限の近い順にソートされている
- [ ] 読了済みの本がリスト最下部に表示される
- [ ] 未ログインアクセス時はログイン画面へリダイレクトされる

### 書籍カード
- [ ] 書籍カードにタイトルが表示される
- [ ] 書籍カードに読了期限が表示される
- [ ] 書籍カードに進捗率が表示される
- [ ] 書籍カードに今日のノルマが表示される
- [ ] 書影未設定時にプレースホルダーが表示される

### ナビゲーション
- [ ] 0冊時にEmpty Stateが表示される
- [ ] 書籍カードクリックで詳細画面へ遷移する
- [ ] 「本を追加する」ボタンが表示される
