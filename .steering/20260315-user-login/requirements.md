# 要求内容

## 概要

GitHub Issue #10「ユーザーログイン機能の作成」の実装。Devise が既にセットアップ済みの状態で、ログインフォーム（W-3 画面）を作成し、認証後に積読一覧画面へリダイレクトする。

## 背景

Issue #4（Devise 導入と User モデル作成）がすでに完了しており、`devise_for :users` でルーティングも設定済み。
しかし Devise のデフォルトビューはまだ生成されておらず、日本語化もされていない。
本 Issue でログインフォームを独自スタイルで実装し、既存のデザイン（BEM + CSS カスタムプロパティ）に合わせる。

## 実装対象の機能

### 1. ログインフォーム（W-3）

- メールアドレス・パスワードの入力フォーム
- 「ログインする」送信ボタン
- 新規登録画面（W-2）への切り替えリンク
- 「パスワードを忘れた場合」リンク（遷移先は Issue #29 で実装予定）

### 2. 認証後リダイレクト

- 認証成功後 → 積読一覧画面（books_path）へリダイレクト
  ※ 積読一覧は Issue #14 で実装予定のため、一時的にルートへフォールバック
- 認証失敗時 → エラーメッセージを表示してログインフォームに戻る

### 3. エラーメッセージの日本語化

- Devise のフラッシュメッセージを日本語で表示する
- `config/locales/devise.ja.yml` を追加し、ロケールを `ja` に設定

## 受け入れ条件

### ログインフォーム
- [ ] 登録済みのメールアドレスとパスワードでログインできる
- [ ] ログイン成功後に積読一覧画面（将来的には books_path）へリダイレクトされる
- [ ] 誤ったメールアドレスまたはパスワードでログインするとエラーメッセージが日本語で表示される
- [ ] 「アカウントをお持ちでない方」リンクから新規登録画面へ遷移できる
- [ ] 「パスワードを忘れた場合」リンクが表示される

### デザイン・スタイル
- [ ] 既存の BEM + CSS カスタムプロパティのデザインと統一されている
- [ ] レスポンシブ対応で主要ブレークポイントでレイアウトが崩れない

### テスト
- [ ] ログイン成功・失敗・未認証アクセスのリクエストスペックが通る

## スコープ外

以下はこのフェーズでは実装しません:

- OmniAuth（Google/Twitter ログイン）
- 2段階認証
- アカウントロック機能
- パスワード再設定フォームの実装（Issue #29）
