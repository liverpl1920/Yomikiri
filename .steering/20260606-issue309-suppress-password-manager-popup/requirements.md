# 要求内容

## 概要

PCブラウザで新規本登録フォームを開いた際、パスワード管理拡張機能（SafeInCloud、Googleパスワードマネージャー等）が「ログイン情報を保存しますか？」というポップアップを表示してしまう挙動を抑制する。

## 背景

本登録フォームのテキスト入力欄が、パスワード管理ツールの拡張機能によって「ユーザー名/パスワード入力欄」として誤認識されている。各フィールドには `autocomplete: 'off'` を設定済みだが、フォーム要素（`<form>`）タグ自体に `autocomplete="off"` が設定されていないため、拡張機能によってはフィールドレベルの設定が無視されることがある。

## 実装対象の機能

### 1. フォームタグへの autocomplete="off" 設定

- `books/_form.html.erb` の `form_with` に `html: { autocomplete: 'off' }` を追加し、フォームレベルでパスワード管理ツールの誤認識を抑制する。

## 受け入れ条件

### フォームの autocomplete 属性

- [ ] `<form>` タグに `autocomplete="off"` 属性が付与されていること
- [ ] 既存フィールドの `autocomplete: 'off'` 設定が維持されること
- [ ] フォームの既存機能（本の登録・更新）に影響がないこと

## スコープ外

- サインインフォーム、サインアップフォームへの対応（Deviseが管理するため対象外）
- JavaScript による動的な属性変更
