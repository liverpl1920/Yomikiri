# 要求内容

## 概要

Issue #187として、各積読にコメント・メモを保存できる機能を追加する。書籍詳細画面で入力・更新し、一覧画面で要約表示できるようにする。

## 背景

現状は進捗・期限管理が中心で、読書中の気づきや次回読む際のメモを本単位で残せない。メモ機能を追加することで、読書体験の継続性と再読時の利便性を向上させる。

## 実装対象の機能

### 1. 書籍メモ入力・保存
- 書籍詳細画面にコメント・メモ入力欄を追加する
- 入力内容をBookに紐づけて保存・更新できる

### 2. メモ表示
- 書籍詳細画面で保存済みメモを表示する
- 積読一覧画面でメモの要約（先頭数十文字）を表示する

### 3. 安全な表示とバリデーション
- Bookモデルに文字数バリデーションを追加する
- 改行を保持しつつXSSに配慮した表示にする

## 受け入れ条件

### 書籍メモ入力・保存
- [ ] 書籍詳細画面でメモを入力して保存できる
- [ ] 保存後に再表示したとき同じ内容が表示される
- [ ] 空文字でも更新でき、メモを削除できる

### メモ表示
- [ ] 書籍詳細画面で改行を保持して表示される
- [ ] 一覧画面で先頭文字列が要約表示される
- [ ] メモ未登録の本では不自然な空表示が出ない

### バリデーション・安全性
- [ ] 文字数上限を超えると保存できずエラー表示される
- [ ] HTMLタグ入力はエスケープされスクリプト実行されない

## 成功指標

- 読了前後の書籍に対してメモ保存導線が追加され、入力完了までの操作回数が現状の詳細画面遷移内で完結する
- request spec / model specで主要な保存・更新・表示整形ケースが検証される

## スコープ外

以下はこのフェーズでは実装しない:

- メモの履歴管理（バージョン管理）
- Markdown記法やリッチテキスト編集
- メモ検索・フィルタ機能
