# 要求内容

## 概要

GitHub Actionsワークフロー `.github/workflows/reading-report-mail.yml` で、毎週土曜日に `reading_reports:weekly` タスクの実行のみが定義されており、月次・年次レポートの自動送信を行うスケジュールが存在しない問題を解消します。
本件は Issue #392 と完全に同一の内容であり、すでに `main` ブランチに #392 の対応としてマージされています。
よって本タスクでは、重複する Issue #390 と #391 を自動的にクローズ（Closes）するためのブランチ作成と PR 作成を目的とします。

## 背景

現在、`.github/workflows/reading-report-mail.yml` のトリガーは毎日 JST 08:00 (UTC 23:00) に `reading_reports:dispatch` タスクを実行するよう修正が完了しています。
Rakeタスク側で日付（週末・月末・年末）判定を行って配信を行うように改修されたため、この変更により週次・月次・年次すべてのレポート自動配信が担保されています。
この修正自体はすでにリリース（マージ）済みのため、対応する Issue #390, #391 を重複として適切にクローズ処理します。

## 受け入れ条件

- [ ] Issue #390 および #391 をクローズするプルリクエストを作成すること。
- [ ] プルリクエストマージ後、両方の Issue が適切にクローズされるよう `Closes #390, Closes #391` を PR 説明文等に含めること。
