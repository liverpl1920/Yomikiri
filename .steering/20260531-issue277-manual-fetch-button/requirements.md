# 要求内容

## 概要

新規登録画面および編集画面におけるタイトル入力起点の書籍情報自動取得を廃止し、ユーザーが明示的に押下する「情報取得」ボタン経由でのみ書籍情報を取得する。

## 背景

- タイトル入力中や blur 時の自動取得により、意図しないタイミングでフォーム値が更新される。
- 取得タイミングをユーザー操作に統一し、手動編集内容の保護と操作意図の明確化を実現する。

## 実装対象の機能

### 1. タイトル入力時の自動取得廃止
- タイトル入力欄の blur / submit 時に自動取得しない。
- オートコンプリート候補表示は維持する（候補選択時の反映は既存仕様）。

### 2. 情報取得ボタンによる手動取得
- 新規登録・編集フォームに「情報取得」ボタンを追加する。
- ボタン押下時のみ `/books/search` を利用した書籍情報取得を実行する。
- 取得中・成功・失敗のステータスメッセージ表示を維持する。

### 3. 手動入力済み項目の上書き抑止
- API取得時、既に値が入っている `author` / `genre` / `total_pages` / `target_pages` / `current_page` は上書きしない。
- `cover_image_url` は未設定時のみ設定する。
- `isbn` は取得値を反映する（識別情報として許容）。

## 受け入れ条件

### 自動取得廃止
- [ ] タイトル入力・blur のみでは情報取得が実行されない。
- [ ] 「登録する」「更新する」押下時にも暗黙の追加取得が実行されない。

### 手動取得ボタン
- [ ] 新規登録画面・編集画面の双方で「情報取得」ボタンが表示される。
- [ ] ボタン押下時のみ情報取得が実行され、ステータス文言が表示される。

### 上書き抑止
- [ ] 手動入力済みの `genre` / `total_pages` / `target_pages` / `current_page` が情報取得後も保持される。
- [ ] 空欄の項目は取得値で補完される。

### 品質
- [ ] 関連システムテストが追加・更新される。
- [ ] `bundle exec rspec`（対象spec）と `bundle exec rubocop` が通過する。

## スコープ外

- `/books/search` API レスポンス仕様自体の変更
- openBD / Google Books / 楽天連携ロジックの刷新
- メモ欄のMarkdown化など他Issueの対応
