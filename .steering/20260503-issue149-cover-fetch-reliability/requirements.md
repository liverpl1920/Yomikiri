# 要求内容

## 概要

Issue #149 の Copilot 指摘を反映し、タイトル検索由来の書影取得を安定化する。特に「Google Books の thumbnail 依存」「429時の導線」「blur発火依存による取りこぼし」を解消する。

## 背景

- Google Books の thumbnail URL はブラウザ表示に失敗するケースがあり、登録後に書影が空または壊れ画像になりやすい。
- Google Books API 429時にタイトル検索が失敗すると、ISBN補完フローが不安定なケースがある。
- 自動取得トリガーが blur のみのため、タイトル入力直後に送信すると取得処理より先に登録される。

## 実装対象

### 1. サーバー側書影URL決定ロジックの改善
- タイトル検索結果から ISBN を抽出し、openBD で利用可能な書影URLを優先して返す。
- Google thumbnail は書影URLとして採用しない（不安定要因を除去）。

### 2. フロントの自動取得タイミング改善
- フォーム送信時にも自動取得を試行し、blur未発火でも取りこぼさない。
- 取得中は送信を一時停止し、完了後に再送信する。

### 3. 429時のISBN補完導線の安定化
- 429等でタイトル検索に失敗した場合、既存のISBNフォールバック導線を維持し、ISBN取得で cover_image_url が確実に反映される。

## 受け入れ条件

- [ ] タイトル検索後に登録した本で書影が表示される（openBD由来URLが保存される）。
- [ ] Google Books API が 429 を返した場合でも、ISBN補完導線で書影を設定できる。
- [ ] タイトル入力後に即送信しても、自動取得が走ってから登録される。

## スコープ外

- cover_image_url カラム削除・画像プロキシ配信API新設
- 一覧/詳細画面のレイアウト刷新
