# 要求定義: 積読一覧画面の検索機能追加 (Issue #184)

## 概要

積読一覧画面で、書籍名・著者名・読了日時（期間）を使った絞り込み検索を提供し、
冊数が多い場合でも目的の本を素早く見つけられるようにする。

## 関連Issue

- GitHub Issue #184: https://github.com/liverpl1920/Yomikiri/issues/184

## 対応画面

- W-4（積読一覧）`/books`

## 実装内容

1. 積読一覧画面に検索フォームを追加する
2. 書籍名（部分一致）で検索できるようにする
3. 著者名（部分一致）で検索できるようにする
4. 読了日時（`completed_at`）の期間（開始日〜終了日）で検索できるようにする
5. 書籍名・著者名・期間の複合条件検索を可能にする
6. 検索条件の保持とクリア導線を実装する
7. 一覧取得クエリを既存のソート仕様（未読/読書中優先・期限順）を維持したまま最適化する
8. request spec を追加して検索仕様を担保する

## 完了条件

- [ ] 書籍名・著者名・読了日時（期間）で検索できる
- [ ] 複合条件検索で期待通りの結果が表示される
- [ ] 期間指定の未入力/片側入力/逆転入力を適切に扱える
- [ ] 検索条件の保持とクリアが正しく動作する
- [ ] 既存一覧表示・ソート機能に回帰がない

## テスト観点

- request spec で書籍名検索・著者名検索・期間検索を検証
- 複合条件検索を検証
- 境界値（期間の片側入力・逆転入力）を検証
