# 要求内容

## 概要

Issue #148 として、積読登録画面の不要入力欄を削除し、タイトル入力起点の自動取得フローに導線を一本化する。

## 背景

- 登録画面に「ISBNまたは書籍名から自動入力」欄と「書影URL」欄が残っており、入力体験が冗長になっている。
- 既存実装ではタイトル欄の blur をトリガーに書誌情報を自動取得できるため、ユーザーに複数の入力導線を提示する必要がない。

## 実装対象の機能

### 1. 登録フォームUIの簡素化
- 「ISBNまたは書籍名から自動入力」セクションを削除する。
- 「書影URL」入力欄を削除する。
- タイトル欄の自動取得ステータスメッセージは維持する。

### 2. 自動取得ロジックの整理
- フォームから削除した入力欄に依存する処理を Stimulus から削除する。
- 取得失敗時は「タイトル起点の自動取得に失敗した」ことを示すメッセージを表示し、追加入力は求めない。

### 3. テストの更新
- 削除されたUIに依存する system spec を更新または不要分を削除する。
- 登録画面で不要欄が表示されないことを検証する。
- 既存 request spec の期待値（検索APIの返却内容）と整合することを確認する。

## 受け入れ条件

### 登録フォームUIの簡素化
- [ ] 新規登録画面に「ISBNまたは書籍名から自動入力」が表示されない。
- [ ] 新規登録画面に「書影URL」が表示されない。
- [ ] タイトル欄、著者欄、ページ数欄、期限欄の登録フローは維持される。

### 自動取得ロジックの整理
- [ ] タイトル欄の blur で著者・総ページ数が自動補完される。
- [ ] 自動取得失敗時はフォーム内メッセージのみ表示し、ISBN手入力導線は表示されない。

### テストの更新
- [ ] 関連 system spec / request spec がグリーンになる。

## 成功指標

- 登録画面の初回表示時に不要入力欄がなく、主要入力導線がタイトル起点で一意に理解できる。
- 既存テストと追加/更新テストが通過し、回帰がない。

## スコープ外

以下はこのフェーズでは実装しない:

- 検索APIエンドポイントの削除や仕様変更
- cover_image_url カラムの削除（DBスキーマ変更）
- 外部APIの再設計
