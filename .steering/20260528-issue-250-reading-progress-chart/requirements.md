# 要求内容

## 概要

書籍詳細画面に、日付ごとの読書ページ数を可視化する折れ線グラフを追加する。ユーザーがどの日にどれだけ読めたかを一目で把握できる状態にする。

## 背景

Issue #250 の要件として、詳細画面で読書進捗を時系列で確認できることが求められている。既存の数値表示だけでは日ごとの波が把握しにくいため、視覚化で進捗確認を補強する。

## 実装対象の機能

### 1. 詳細画面の読書進捗折れ線グラフ
- 書籍詳細画面に折れ線グラフを表示する
- 横軸は日付、縦軸はその日に読んだページ数とする

### 2. グラフ描画用データの整形
- 表示期間を「読書開始日から今日まで（読了本は読了日まで）」として日次データを生成する
- 記録がない日は 0 ページとして補完し、折れ線を連続表示する

## 受け入れ条件

### 詳細画面の読書進捗折れ線グラフ
- [ ] 詳細画面に「読書進捗グラフ」セクションが表示される
- [ ] 横軸の日付ラベルと縦軸のページ数が確認できる
- [ ] 折れ線で日別読書ページ数が確認できる

### グラフ描画用データの整形
- [ ] 表示期間が未読/読書中は今日まで、読了本は読了日までになる
- [ ] 記録がない日が 0 ページとして表示される
- [ ] 読書ログがない場合も画面が崩れず空状態メッセージを表示する

## 成功指標

- ユーザーが詳細画面で日別ページ数の推移を直感的に確認できる
- 既存の詳細画面（進捗更新、メモ、読了操作）の動作に回帰不具合がない

## スコープ外

以下はこのフェーズでは実装しない:

- 外部グラフライブラリ導入（Chart.js など）
- 期間切り替え UI（週次/月次）
- 集計粒度の変更（週単位・月単位）
