# Issue #305 要件定義

## 概要

書籍登録・編集フォームにおいて、任意の項目の個別「補完」ボタンを押した際、
書籍データのキャッシュがブラウザ側に存在しない場合にフォーム全体が一括入力されてしまうバグを修正する。

## 現象

- 個別補完ボタン（例：「翻訳者」）を押したとき、キャッシュが存在しない場合は API からデータを取得する。
- しかし `_performFetchByTitle` は一括取得処理と共通化されており、内部で `_fillFormFromSearch` を無条件に呼び出してしまう。
- 結果として、押した補完ボタンの項目だけでなく、他の空欄項目（著者、出版社など）も一括で自動入力されてしまう。

## 期待される挙動

- 個別補完ボタンが押された場合、指定された特定の項目のみが自動入力される。
- 他の項目は変更されない。
- キャッシュが存在する場合は従来通り正常に動作する。

## 対象ファイル

- `app/javascript/controllers/book_form_controller.js`
- `spec/system/books/book_form_single_field_fetch_spec.rb`（バグ再現テストの追加）

## 制約

- 既存の「情報取得」ボタンによる一括自動入力は引き続き正常に動作すること。
- キャッシュ機能は維持すること。
