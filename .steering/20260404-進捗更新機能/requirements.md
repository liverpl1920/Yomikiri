# 要求仕様: 進捗更新機能 (Issue #19)

## 概要
W-6（書籍詳細）の進捗記録フォームの実装

## 関連Issue
GitHub Issue #19: https://github.com/liverpl1920/Yomikiri/issues/19

## 対応画面
W-6（書籍詳細）`/books/:id`

## 実装内容

1. 「今日読んだページ数」入力フォームを作成する（デフォルトの入力方法）
2. 入力された値を `current_page` に加算して更新する
3. ±ボタンによるページ数の増減を実装する
4. 上級者向け「現在ページを直接入力」フォームを折りたたみ表示で実装する
5. 更新後にノルマが再計算される
6. `current_page` が `target_pages` を超えないバリデーションを実装する（既存バリデーション活用）

## 完了条件

- 「今日読んだページ数」入力で `current_page` が正しく更新される
- ±ボタンで増減が動作する
- 折りたたみから現在ページの直接入力が可能
- 更新後にノルマが再計算・再表示される
