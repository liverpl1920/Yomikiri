# 要求内容

## 概要

ログイン後、ユーザーが進行中の本、今日の合計ノルマ、直近の読了状況、読書ストリークやアクティビティグラフを一覧で確認できる「ダッシュボード」画面を新設します。

## 背景

ユーザーが現在の積読の進捗状況や、日々の読書目標、継続状況（ストリーク）、過去の読書履歴（アクティビティ）をひと目で確認できるようにすることで、読書のモチベーションを維持・向上させるため。

## 実装対象の機能

### 1. ダッシュボード画面の新設
- ログイン後の初期画面としてダッシュボードを表示する。
- 以下のコンポーネントを配置する：
  - Welcomeヘッダー（ニックネームまたはメールアドレスでの歓迎メッセージ）
  - 進行中の本（Current Reads）（進行中・未読の書籍リストとそれぞれの進捗バー、今日のノルマ）
  - 読書統計（Reading Stats）（総読了ページ数・総読了冊数・現在の読書ストリーク）
  - 目標進捗（Reading Goal）（今日の全書籍のノルマ合計値）
  - アクティビティグラフ（Reading Activity）（過去7日間の日別読了ページ数を表す棒グラフ）
  - 最近読了した本（Recently Finished）（最近読了した本（最大3冊など）のリスト）

### 2. ルーティングとログイン後リダイレクトの制御
- `/dashboard` パスでダッシュボード画面を表示する。
- ユーザーログイン後の遷移先を、従来の `books_path` から `dashboard_path` に変更する。

### 3. ヘッダーメニューの更新
- ログイン中のヘッダーメニュー（ドロップダウン）に「ダッシュボード」へのリンクを追加する。

## 受け入れ条件

### ダッシュボード画面
- [ ] ログイン後に `/dashboard` にアクセスすると、ダッシュボード画面が表示されること。
- [ ] ログインしていないユーザーが `/dashboard` にアクセスした場合は、ログイン画面にリダイレクトされること。
- [ ] 進行中の本（未読・読書中）が表示され、それぞれの書籍について「進捗率」「残り日数」「今日のノルマ」が表示されること。
- [ ] 今日の目標進捗（ノルマ合計）が正しく計算され表示されること。
- [ ] 総読了ページ数、総読了冊数、連続読書日数（ストリーク）が正しく表示されること。
- [ ] ストリークが、`ReadingLog`（読書記録）に基づいて正しく計算されること。
- [ ] 過去7日間の日別読了ページ数が集計され、CSSを用いた美しいアクティビティ棒グラフとして表示されること。
- [ ] 最近読了した本（ステータスが completed の本）が最大3冊、読了日の新しい順に表示されること。

### リダイレクトとヘッダー
- [ ] ログイン完了後、ダッシュボード画面 (`/dashboard`) に自動的にリダイレクトされること。
- [ ] ヘッダーのドロップダウンメニューに「ダッシュボード」へのリンクがあり、クリックするとダッシュボード画面へ遷移すること。

## 成功指標

- ログイン後に自動でダッシュボードが表示され、ユーザーが現在の進捗やストリークをひと目で把握できるようになること。
- CSS による美しいグリッドレイアウトおよびアクティビティグラフが、Forest Nook テーマに沿ったデザインで表示されること。

## スコープ外

以下はこのフェーズでは実装しません:
- グラフのライブラリ（Chart.js等）の導入（今回は純CSSの棒グラフで実装します）。
- ダッシュボード上での直接的な読書進捗更新（進捗更新は各書籍の詳細画面で行うため、ダッシュボードからは各書籍詳細へのリンクを貼るに留める）。
