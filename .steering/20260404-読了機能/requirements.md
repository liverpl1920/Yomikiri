# 要求定義: 読了機能の作成 (Issue #21)

## 概要

W-6（書籍詳細）の読了ボタンと W-13（読了お祝いモーダル）の実装

## 対応画面

- W-6（書籍詳細）
- W-13（読了お祝いモーダル）

## 実装内容

1. `current_page >= target_pages` の場合、「読了にする！」ボタンを強調表示する
2. ボタン押下で `status` を「読了（2）」に更新し、`completed_at` に現在日時をセットする
3. 読了お祝いモーダル（W-13）を実装する
   - 読了おめでとうメッセージ
   - 読了した書籍名・読了日・読了までの日数を表示
   - 「一覧に戻る」ボタン
4. モーダルの「一覧に戻る」で積読一覧画面（W-4）へ遷移する
5. 読了済みの書籍は一覧画面で視覚的に区別する

## 完了条件

- [ ] 進捗が100%到達時に「読了にする！」ボタンが強調表示される
- [ ] 読了にすると `completed_at` が記録され、お祝いモーダルが表示される
- [ ] モーダルから一覧画面に正しく遷移する
